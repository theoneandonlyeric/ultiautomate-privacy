UltiAutoMate – Datenschutzerklärung

Anbieter: UA-Labs
Kontakt: ultiautomatesupport@ikmail.com

1. Allgemeines

UltiAutoMate ist eine Android-App zur benutzerdefinierten Automatisierung von Bedienabläufen auf dem Gerät. Der Schutz der Privatsphäre der Nutzer ist ein wesentlicher Bestandteil der App. UltiAutoMate 1.0 verarbeitet die für ihre Funktionen erforderlichen Daten lokal auf dem Gerät und übermittelt diese Daten nicht an Server von UA-Labs.

2. Benutzerkonto und Internetverbindung

UltiAutoMate erfordert kein Benutzerkonto und keine Anmeldung. Die App enthält keine Werbung, keine Analyse- oder Tracking-Dienste und verwendet keine UA-Labs-Server zur Verarbeitung von Automatisierungsdaten. UltiAutoMate 1.0 fordert keine allgemeine Android-INTERNET-Berechtigung an.

3. Bedienungshilfedienst (AccessibilityService)

UltiAutoMate verwendet die Android AccessibilityService API als wesentlichen Bestandteil seiner benutzerdefinierten UI-Automatisierungsfunktionen. Nutzer erstellen und starten ihre eigenen deterministischen Automatisierungsabläufe.

Der Bedienungshilfedienst ermöglicht UltiAutoMate, sichtbare Benutzeroberflächenelemente und Bildschirminhalte zu erkennen und vom Nutzer konfigurierte Interaktionen wie Klicks und Gesten auszuführen.

Je nach vom Nutzer erstellter Automatisierung kann der Dienst sichtbaren Text, Eigenschaften und Positionen von UI-Elementen sowie Bildschirminhalte verarbeiten, soweit dies zur Erkennung von Automatisierungszielen erforderlich ist. Diese Informationen werden in UltiAutoMate 1.0 lokal auf dem Gerät verarbeitet und nicht an Server von UA-Labs übertragen.

UltiAutoMate führt Automationen entsprechend den vom Nutzer festgelegten Schritten, Bedingungen und Regeln aus. Die App plant oder initiiert nicht selbstständig, welche Aktionen ausgeführt werden sollen.

4. Screenshots, Bilder und Texterkennung (OCR)

Für Funktionen zur Zielerkennung kann UltiAutoMate Bildschirminhalte, Screenshots, Referenzbilder und mittels OCR erkannten Text lokal verarbeiten. Diese Inhalte werden nicht an Server von UA-Labs übertragen.

5. Skripte, Projekte, Variablen und Einstellungen

Vom Nutzer erstellte Skripte, Projekte, Variablen, Einstellungen und sonstige Automatisierungsdaten werden lokal auf dem Gerät verarbeitet bzw. gespeichert. Export- und Importfunktionen werden vom Nutzer selbst ausgelöst. Der Nutzer entscheidet selbst, wo exportierte Dateien gespeichert oder weitergegeben werden.

6. Datenübermittlung an UA-Labs

UltiAutoMate 1.0 übermittelt keine Bildschirm-, OCR-, Bild-, Skript- oder Automatisierungsdaten an UA-Labs. UA-Labs verwendet innerhalb der App keine Werbe-, Analyse- oder Tracking-SDKs.

7. Support

Wenn Nutzer UA-Labs freiwillig per E-Mail kontaktieren, werden die dabei übermittelten Informationen ausschließlich zur Bearbeitung der jeweiligen Anfrage verwendet. Für die Verarbeitung durch den verwendeten E-Mail-Dienst können zusätzlich dessen Datenschutzbestimmungen gelten.

8. Google Play und Android

Google Play, Android, der Gerätehersteller oder andere vom Nutzer verwendete Apps und Dienste können unabhängig von UltiAutoMate eigene Daten verarbeiten. Für diese Verarbeitung gelten die jeweiligen Datenschutzbestimmungen der entsprechenden Anbieter.

9. Löschung lokaler Daten

Lokal gespeicherte UltiAutoMate-Daten können durch die entsprechenden Funktionen der App oder durch Löschen der App bzw. ihrer App-Daten vom Gerät entfernt werden. Exportierte Dateien unterliegen der Kontrolle des Nutzers und müssen gegebenenfalls separat gelöscht werden.

10. Änderungen dieser Datenschutzerklärung

Diese Datenschutzerklärung kann angepasst werden, wenn sich Funktionen der App oder rechtliche bzw. technische Anforderungen ändern. Die jeweils aktuelle Fassung wird unter dieser Adresse veröffentlicht.

UltiAutoMate – Privacy Policy

Provider: UA-Labs
Contact: ultiautomatesupport@ikmail.com
Last updated: September 17, 2026

1. General

UltiAutoMate is an Android application for user-defined automation of on-device user interface workflows. User privacy is an important part of the application. UltiAutoMate 1.0 processes data required for its functionality locally on the device and does not transmit this data to UA-Labs servers.

2. User accounts and internet access

UltiAutoMate does not require a user account or sign-in. The application contains no advertising, analytics or tracking services and does not use UA-Labs servers to process automation data. UltiAutoMate 1.0 does not request the general Android INTERNET permission.

3. AccessibilityService

UltiAutoMate uses the Android AccessibilityService API as a core part of its user-defined UI automation functionality. Users create and start their own deterministic automation workflows.

The AccessibilityService allows UltiAutoMate to identify visible user interface elements and screen content and to perform user-configured interactions such as clicks and gestures.

Depending on the automation configured by the user, the service may process visible text, UI element properties and positions, and screen content required to identify automation targets. In UltiAutoMate 1.0 this information is processed locally on the device and is not transmitted to UA-Labs servers.

Automation follows the steps, conditions and rules explicitly defined by the user. UltiAutoMate does not autonomously initiate or plan which actions should be performed.

4. Screenshots, images and OCR

For target-recognition functionality, UltiAutoMate may locally process screen content, screenshots, reference images and text recognized using OCR. This content is not transmitted to UA-Labs servers.

5. Scripts, projects, variables and settings

Scripts, projects, variables, settings and other automation data created by the user are processed or stored locally on the device. Export and import functions are initiated by the user. Users decide where exported files are stored or shared.

6. Data transmission to UA-Labs

UltiAutoMate 1.0 does not transmit screen, OCR, image, script or automation data to UA-Labs. UA-Labs does not use advertising, analytics or tracking SDKs within the application.

7. Support

If users voluntarily contact UA-Labs by email, information provided in that communication is used only to handle the corresponding request. The privacy terms of the email service used may additionally apply to that processing.

8. Google Play and Android

Google Play, Android, the device manufacturer, or other applications and services used by the user may process data independently of UltiAutoMate. Their respective privacy policies apply to such processing.

9. Deletion of local data

Locally stored UltiAutoMate data can be removed using the corresponding app functions or by deleting the application or its app data from the device. Exported files remain under the user's control and may need to be deleted separately.

10. Changes to this Privacy Policy

This Privacy Policy may be updated when application functionality or legal or technical requirements change. The current version will be published at this address.
